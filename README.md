# Object-Detection & Color Composition
This repository includes relevant files for an object detection analysis.
I have included the IPYNB file that contains the code used for each image. Each code line has the YOLO and Faster RCNN code for each image. This code prints the image and summary of each module of object detection. I included a variety of images that is relevant to me. All images used were collected from pinterest and none are AI generated.
The second part of the assignment analyses colors in the image. I used the basic everyday colors: green, blue, red, yellow, purple, white, grey, black. The colors also capture soley the pure state of it, so in a RGB scale, Red would only show values for pixels with the matrix of (255, 0, 0).
